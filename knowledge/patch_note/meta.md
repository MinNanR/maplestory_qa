# 版本更新公告（Patch Notes）

本文件夹收录冒险岛（MapleStory，GMS / Nexon 官方公告）**各版本更新公告（Patch Notes）的结构化知识摘要**，一篇公告一篇文档，数据源为 nexon.com 官方更新公告页（经本机调试浏览器 CDP 抓取）。每篇覆盖该版本的：新增内容与系统改版、升级/成长曲线调整、技能与职业改动梗概（HEXA 通用节点、Erda Link 技能石等）、BOSS 与怪物调整、地图/NPC、道具产出与下架清单、UI/便利性改动，以及全部同期活动（联动、季节活动、子系统活动）的**时间窗口、参与条件、奖励清单与限购**。可直接回答「某版本更新了什么」「某次改动是哪一版上线的」「某活动的开放时间与奖励」「某道具/火焰/戒指在哪一版被改动或下架」「某职业的 HEXA 通用节点叫什么」等版本相关问题；也可用于对比版本演进（成长曲线、火花体系、特殊技能戒指等）。版本相关的机制细节仍可结合 `system/`（伤害公式、星之力、火花、Utility）与 `job_skill/`（各职业技能数值）交叉查询。

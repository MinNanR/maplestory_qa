# 冒险岛伤害计算公式

> 来源：StrategyWiki — MapleStory/Formulas（https://strategywiki.org/wiki/MapleStory/Formulas）
> 说明：所有百分比属性按**整数**处理；公式中的取整规则务必注意（大部分向下取整）。

## 一、属性体系（伤害的输入）

4 大属性：**STR、DEX、INT、LUK**。"All Stats" 仅指这四项。属性分 4 层：

### 1.1 基础属性 Pure Stats

- 每项默认 4，由 AP 加点提升。
- AP 总量：转职前 `4 + Level×5`；3 转 `9 + Level×5`；4 转及以后 `14 + Level×5`。Lv300 最多 **1514 AP**。
- Demon Avenger 的 Pure HP：`基础值 + 90×Level`（1转 220 / 2转 395 / 3转 470 / 4转 545，后续转职以 5 AP 形式补差；每 AP 给 15 Pure HP）。

### 1.2 追加属性 Added Stats

- 任何**非百分比**且**受百分比影响**的加成（装备、潜能、BUFF、套装等）。
- 以下**不属于**追加属性（不进百分比乘区）：超属性（四维）、神秘符文（Arcane Symbol）、真实符文（Authentic Symbol）、内在能力（四维）、联盟攻击者效果。
- 按基础属性比例增加的技能（4转冒险家勇士 +15%~16%、5转海盗旗帜 +10%~25%）**先向下取整**再计为追加属性。
- 职业特例：Demon Avenger 装备/套装的非百分比 HP **减半**；Kanna 装备的非百分比 MP 转为追加 HP。
- **基础总属性 = Pure + Added，向下取整**。

### 1.3 百分比属性 Percentage Stats

- 按"基础总属性"的百分比增加，结果**向下取整**。
- All Stats% 与单项 STR/DEX/INT/LUK% 为**相加**关系（非相乘）。
- 常见来源：装备潜能、链接技能（Xenon +5/10% 四维、Kaiser +10/15% HP 等）、装备附加潜能（仅四维）、超属性（仅 HP/MP）、套装效果（通常仅 HP/MP）、炼金药水（全属性 +5/10%）。

### 1.4 最终属性 Final Stats

- **非百分比**、**不受百分比影响**的固定加成。来源极少：
  - 超属性（四维）、神秘/真实符文、内在能力（四维）、联盟攻击者效果。
  - 最终 ATT/魔攻：内在能力"按等级加 ATT"（每 10~16 级 +1，向下取整）；Kanna 元素祝福（每 700 最终 MaxHP +1 最终魔攻，上限 500,000 HP = +714）；怪物农场光之超越者（每 20 级 +1 最终 ATT 与魔攻）。

### 1.5 最终总属性

```
最终总属性 = 基础总属性 × (1 + 属性%/100) + 最终属性 ，向下取整
```

四维、HP、MP、DEF、ATT、魔攻各自独立按此式计算。

### 2.2 熟练度 Mastery

- 影响伤害**下限**，上限不变；默认 20%，**上限 99%**；每击独立判定（同一技能多次命中可部分暴击/部分低伤）。

### 2.3 属性值 Stat Value

- 一般职业：`伤害 ∝ 主属性×4 + 副属性`。
- Demon Avenger：`floor(PureHP/3.5) + 0.8×floor((TotalHP−PureHP)/3.5) + STR`
  - TotalHP 忽略 50 万实用上限；两组**分别向下取整再相加**（余数不合并，差 1~3 HP 可能完全不影响伤害范围）。
  - Pure HP 比其他来源 HP 值钱 25%。

| 职业 | 主属性 | 副属性 |
|---|---|---|
| 战士（除 DA） | STR | DEX |
| 法师 | INT | LUK |
| 弓手 | DEX | STR |
| 飞侠（影刃/双刀/卡德娜） | LUK | DEX+STR |
| 飞侠（其他） | LUK | DEX |
| 海盗（火枪/天使破坏者） | DEX | STR |
| 海盗（拳套/加农炮） | STR | DEX |
| Demon Avenger | HP | STR |
| Xenon | STR+DEX+LUK | — |

### 2.4 伤害% Damage%（TD%）

- **加法**叠加，作用于所有攻击（含灵魂武器召唤）；条件性加成不显示在属性窗。
- 来源：链接技能（DA +5/10/15%、Kanna +5/10%、Illium 移动、Ark 攻击、AB +30/45/60% 等）、超属性 +3~45%、武器/副手/纹章潜能 +1~13%/行、武器附加潜能 +1~7%、联盟神器 +1.5%/级（上限 15%）、公会技能、炼金药水 +5/10%、内在能力异常状态增伤 +2~10% 等。

### 2.5 普通怪伤害% / BOSS伤害%（NBD% / BD%）

- 与 Damage% 同为**加法**并入公式（打对应目标时）。
- 普通怪伤害对怪物公园怪同样生效（但按技能对 BOSS 分支的倍率计算）；BD% 不含怪物公园怪。
- 来源示例：超属性 +3~55%、内在能力 +2~10%（普通）/ +5~20%（BOSS）、联盟棋盘 +1/格（上限 +40%）、武器潜能 BOSS +3~40%/行、Fafnir/Absolab/Arcaneshade 武器 +30%、炼金药水 +10/20%、公会技能等。

### 2.6 最终伤害 Final Damage

```
总最终伤害% = 100 × [(1+F₁/100)×(1+F₂/100)×…×(1+Fₙ/100)] − 100
```

- 各来源**互相乘法叠加**，永不穷尽；属性窗四舍五入，计算保留小数。
- 主要来自技能；创世武器解放后提供 +10% 最终伤害。
- **Reboot 世界**等级梯度：Lv1-99 +15% → Lv100-149 +20% → Lv150-199 +25% → Lv200-249 +35% → Lv250-299 +45% → Lv300+ 保持 45%。

### 2.7 无视防御 Ignore DEF

```
总无视% = 100 − [100×(1−ID₁/100)×(1−ID₂/100)×…×(1−IDₙ/100)]
```

- **乘法**叠加：同一装备多条、超属被动 + 5转 Lv40 强化被动均视为独立来源（20%+20% = 36% 而非 40%）。
- 例外：强化减防 debuff 的超属被动，先加再乘（30% 减防 + 20% 强化 = 50% 减防）。
- 新增来源实际收益 = `新来源% × (1 − 当前总无视%/100)`。
- 怪物 DEF 以百分比形式按剩余比例减免最终伤害，**怪物 DEF 最高按 500% 计**。
- 来源：链接技能（零 +2~10%、Luminous +10~20%、Ho Young +5/10%）、联盟 +1/格（上限 40%）、野心特性（每 5 级 +0.5%，上限 10%）、超属性 +3~45%、武器潜能 +3~40%/行、Fafnir 武器 +10% / Arcaneshade 武器 +20%、联盟神器 +2%/级（上限 20%）、公会技能、炼金药水 +10/20% 等。

### 2.8 怪物属性抗性

| 抗性 | 最终伤害修正 |
|---|---|
| 弱 Weak | +50% |
| 中性 Neutral | 0% |
| 强/抵抗 Strong | −50% |
| 免疫 Immune | −100% |

- 无视属性抗性**乘法**生效（10% 无视强抗：−50% → −45%，不是 −40%）。
- 来源：洞察特性（每 10 级 +0.5%，上限 5%）、自身技能 +10%（火毒/冰雷三转属性削减、圣骑天怒、Luminous Arcane Pitch、Evan 属性重置等）、对怪减抗 debuff +10%（Bishop、夜行、魂骑士 True Sight 等，同类别只取其一）。

### 2.9 暴击率 Critical Rate

- 命中暴击的概率，**上限 100%**（5转 Critical Reinforce 可突破上限，但不增加额外效果），每击独立判定。
- 来源：基础 +5%、Decent Sharp Eyes +10%（不叠加）、链接技能（幻影 +10~20%、战灵 +4~10%、弓手 +3~10%）、超属性 +1~25%、内在能力 +5~30%、武器/副手/纹章潜能 +1~12%/行、灵魂武器 +5~12%、联盟 +1/格（上限 40%）、炼金药水 +3~10% 等。
- 特例：临界转换戒指等**替换**暴击率为"基础主属性的 9%/10%"（DA 按 AP 加的 HP 数、Xenon 按基础 LUK）。

### 2.10 暴击伤害 Critical Damage

- 仅在暴击命中时生效；每次暴击在该区间**随机取值**，逐击独立：
  - 下限：`20% + 暴击伤害属性%`
  - 上限：`50% + 暴击伤害属性%`
- 来源：超属性 +1/级（上限 +15%）、联盟 +0.5%/格（上限 +20%）、手套传说潜能 +1~8%、Decent Sharp Eyes +8%、暴击伤害戒指 +7~28%、HEXA 属性 +0.35%/级（上限 14%）、公会技能等。
- 剑豪特例：初心者被动"岛田之心"每 1 DEF +0.005% 暴击伤害（上限 9999 DEF = +49.995%），**非暴击也生效**。

## 三、伤害范围 Damage Range

**不装备武器时**：伤害范围 = 0，无法攻击（海盗除 Xenon 例外：上界 = `1.43×属性值/100`，下界 = 上界/5，可空手攻击甚至用部分技能）。

**装备武器时**：

```
上界实际 = 武器倍率 × 属性值 × 总Job ATT / 100 ，四舍五入
下界实际 = 上界实际 × 熟练度% / 100 ，四舍五入
上/下界显示 = 实际 × (1 + Damage%/100) × (1 + 最终伤害%/100) ，向下取整
```

- 法师武器用**总魔攻**，其他武器用**总物攻**。
- 显示上限 999B 999M 999K 999，**实际伤害输出无此上限**。
- 打普通/BOSS 怪时用"实际范围"，TD% 与 NBD%/BD% 分别加合。
- 终极戒指（Ultimatum Ring）激活时上界实际伤害强制 = 2,000,000。

## 四、等级优势倍率（最终伤害修正）

作用于所有计算之后（"DEF 转伤害"内在能力之前）。

**一般攻击**（灵魂武器召唤与 DOT 除外）：

| 我的等级 − 怪物等级 | 最终伤害修正 |
|---|---|
| +5 或更高 | +20% |
| +4 / +3 / +2 / +1 | +18% / +16% / +14% / +12% |
| 0 | +10% |
| −1 ~ −4 | 每级 −2.5%p（截断），−4 级共 −8.2% |
| −5 及以上 | 每级 −2.5%p（截断），−40 级 = −100% |

规则速记：**高于 0 级 +10% 起，每高 1 级 +2%p 封顶 +20%；低 1~4 级每级 −2.5%p（最多 −10%）；低 5 级起每级 −2.5%p（−40 级归零）**。

- 米哈儿"女皇祈祷"BUFF 下：低 1~4 级每级只 −2%p，低 5 级起无惩罚。
- **灵魂武器召唤 / DOT**：无等级奖励，只按每级 −2.5%p 惩罚（−40 级 −100%）。

## 五、地图力（Force）修正

同样在所有计算之后、DEF 转伤害之前。

### 5.1 星力图（Star Force）

| 达标比例（向下取整） | 最终伤害修正 |
|---|---|
| 0% ~ 9% | −100%（最低伤害 1） |
| 10% ~ 29% | −90% |
| 30% ~ 49% | −70% |
| 50% ~ 69% | −50% |
| 70% ~ 99% | −30% |
| 100% | 0% |
| 超出 | **每超出 1 星 +1%p，最高 +20%** |

- 星力来源：装备强化（Overall 每星算 2 点，其他每星 1 点）；普通装备上限 5~25 星、高级装备 3~15 星（按装备等级档位）。
- 特定称号/公会被动 +5/10/15 星力**仅用于抵消星力图惩罚**。

### 5.2 神秘之力图（Arcane Force, ARC）

| 达标比例 | 最终伤害修正 |
|---|---|
| 0% ~ 9% | −90% |
| 10% ~ 29% | −70% |
| 30% ~ 49% | −40% |
| 50% ~ 69% | −30% |
| 70% ~ 99% | −20% |
| 100% ~ 109% | 0% |
| 110% ~ 129% | +10% |
| 130% ~ 149% | +30% |
| 150% 及以上 | **+50%** |

### 5.3 真实之力图（Authentic Force）

- 每低于要求 **1 点 −1%p**（最大 −95%，即低 95 点以上）。
- 每高于要求 **2 点 +1%p**（向下取整，最大 +25%，即高 50 点以上）。

## 六、最终输出公式 Output

### 6.1 一般攻击（主动技能 / 角色召唤 / 安置技）

受：物理/魔法无效化、暴击率/暴击伤害、Damage%、BD%、NBD%、最终伤害、怪物 DEF、怪物抗性、地图力、等级优势、熟练度。

**对普通怪（非暴击、0% DEF、无抗性）**：

```
HitDamage = ShownDamage/(1 + TD%/100) × Skill%/100 × (1 + (TD% + NBD%)/100)
```

**对 BOSS**：

```
HitDamage = ShownDamage/(1 + TD%/100) × Skill%/100 × (1 + (TD% + BD%)/100)
```

**附加倍率**：
- 暴击：`(1 + 暴击伤害%/100)`（暴击伤害% 在上下限间随机）
- 怪物 DEF：`1 − [怪物DEF%/100 × (1 − 无视DEF%/100)]`
- 抗性：免疫 = `无视抗性%/100`；强 = `0.5×(1+无视抗性%/100)`；中性 = 1；弱 = 1.5

说明：
- ShownDamage 在上下显示范围间随机；普通攻击 Skill% = 100。
- 影分身等分身攻击的 Skill% 再乘分身常数。
- **单行伤害上限 1500 亿**；Ring of Torment/赎罪戒指期间 1050 亿（箭雨弹等按 Skill%/100 放大上限）。

### 6.2 持续伤害 DOT

受：魔法无效化、怪物抗性、地图力、等级优势、无视抗性。
**不受**：熟练度、怪物 DEF、暴击、Damage%、BD%、NBD%、最终伤害。

```
DOT = UpperActual × Skill%/100 × 抗性倍率
```

（抗性倍率同上：免疫=无视抗性%/100；强=0.5×(1+无视抗性%/100)；中性=1；弱=1.5；力差不足按负最终伤害计。）

### 6.3 灵魂武器召唤 Soul Weapon Summons

受：物理/魔法无效化、**开关型+被动 Damage%**（含条件型非普通/BOSS 伤害%）、最终伤害、等级优势、熟练度、地图力、怪物抗性。
**不受**：暴击率、限时 BUFF 伤害%、BD%、NBD%、怪物 DEF、无视抗性。

```
SoulWeapon = ActualDamage × Skill%/100 × (1 + TD%/100) × (1 + Final%/100) × 抗性倍率
```

（ActualDamage 在上下实际范围间随机；免疫抗性时仅造成 1 点伤害。）

## 七、加成类型速记（判定规则）

- 技能描述为 **+%（加法 / percentage points）** → 直接并进技能 Skill% 的加法区。
- 技能为**乘法**增伤 → 当作 Damage%，并入 TD%（含超属强化技能，但 DOT 与分体超属除外）。
- 技能为**最后乘法** → 当作最终伤害%，并入 Final%，多来源互相乘法。
- **DEF 转伤害内在能力**：在所有计算**之后**加法追加（公式中不体现）。
- **Stat Equivalence（属性等价）**：以"最终伤害等价"衡量 无视DEF / BOSS伤 / ATT% 的相对收益，随角色当前配置变化；页面提供 Desmos 在线图与判断规则（三者中出现 2 次同色的属性即为短板；若 3 图全不确定则属性配比均衡）。
